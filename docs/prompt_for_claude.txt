## Strategy rules (already implemented — do not change the logic)

LEVEL FORMULA (NQ_PARAMS):
  sigma_day      = cash_open * (vxn_prior_close / 100) / sqrt(252)
  imp_up/dn      = cash_open ± 1.25 * sigma_day
  IB window      = 60 minutes from 09:30 ET
  ib_ext_up/dn   = ib_high/low ± ib_range
  upper_level    = (ib_ext_up + imp_up) / 2 - 15.75
  lower_level    = (ib_ext_dn + imp_dn) / 2 + 15.75
  Level live-at  = first bar at/after 10:30 ET

ENTRY:
  - Fade upper_level SHORT on first touch from below (prev close < level, bar high >= level)
  - Fade lower_level LONG  on first touch from above (prev close > level, bar low  <= level)
  - Only ONE entry per level per session
  - Levels stay active for LINE_DAYS=20 sessions from creation
  - Entry window: from level creation (≈10:30 ET) through 11:00 ET only
  - No new entries between 11:00 and session end

STOP / EXIT:
  - Initial stop: sl_pts below entry (long) / above entry (short)  ← tune this param
  - Conditional BE@45: at bar 45 from entry, if trade is in profit → move stop to entry
  - Trailing stop: once unrealised profit hits 200 pts, arm a 20-pt trail behind running peak
    (trail stop = entry + (peak_unreal - 20) for long, mirror for short)
    Stop when trail is triggered → classified as TP
  - Exit at stop hit: if within ±5 pts of entry → BE; if trail armed → TP; otherwise → SL
  - Session cutoff: force-close any open position at 15:00 ET (classified as "cutoff")

SAL (Stop-After-Loss):
  - If a trade exits as SL in a session, no further entries that session
